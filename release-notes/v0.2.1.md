## Notka v0.2.1

### What's new

- **Reminders.** Notka shows a Windows notification 15 minutes before a task that has a time, with Done and Snooze (15 min) buttons. Tasks that only have a date, and overdue ones, are summarized once a morning from 9:00. Reminders can be turned off in Settings.
- **Settings.** The reminders switch sits next to the update and AI agent options.

### Updating

If you run v0.2.0, Notka offers this version from Settings (or within a day automatically). If you run v0.1.0, download `Notka-win-x64.zip` once and extract it over your Notka folder.

### Downloads

- `Notka-win-x64.zip`: unzip and run `Notka.Desktop.exe`. No .NET installation needed.
- `Notka-win-x64.zip.sha256`: the checksum used by the updater.

The app is unpackaged and not code-signed, so Windows SmartScreen may warn on first launch.
