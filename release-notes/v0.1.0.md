## Notka v0.1.0

First public release of Notka, a private Windows 11 app for tasks and sticky notes that can also be driven from Claude Desktop.

### Highlights

- **Tasks and notes.** Tasks with due dates and priorities, colored sticky notes with pinning, search, and live updates across the app.
- **Compact view.** A narrow Sticky Notes style window with a Notes | Tasks switch, optional always-on-top, and remembered mode and size.
- **Taskbar strip.** Today's task summary next to the clock, with a hover card. It works on several monitors, adapts to the number of taskbar apps, hides with an auto-hidden taskbar (OLED friendly), and can be shown as text only.
- **Claude Desktop (MCP).** A stdio MCP server exposes tasks and notes to Claude Desktop.
- **Local and private.** Everything is stored in a local SQLite database. The local API accepts only loopback requests and uses a per-launch bearer token.

### Downloads

- `Notka-Desktop-win-x64.zip`: unzip and run `Notka.Desktop.exe`. No .NET installation needed.
- `Notka-Mcp-win-x64.zip`: point the Claude Desktop configuration at `Notka.Mcp.exe`.

The app is unpackaged and not code-signed, so Windows SmartScreen may warn on first launch.
