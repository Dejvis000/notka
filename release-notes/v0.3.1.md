## Notka v0.3.1

### What's new

- **Taskbar strip fix.** When nothing was left to do today but a task was overdue, the strip text ("! 1 zaległe") was shorter than the minimum width, so the strip was hidden and never came back. Short texts now show whenever there is room.
- **Timing log.** Notka now records how long things take: startup phases, API requests, window and settings opening, tab switches, the strip and reminders, plus a per-minute line with CPU, memory and thread counts. It is written to `%LOCALAPPDATA%\Notka\logs\perf-*.log` (14 days kept), contains only names and numbers (no task or note text) and never leaves your computer.
- **Quieter main log.** Strip layout and placement details moved to the debug level, so `notka-*.log` no longer fills up with them.

### Updating

Notka offers this version from Settings (or within a day automatically) when you run v0.3.0. If you run v0.2.2 or older, follow the manual steps in the v0.3.0 notes once.

### Downloads

- `Notka-win-x64.zip`: unzip and run `Notka.exe`. No .NET installation needed.
- `Notka-win-x64.zip.sha256`: the checksum used by the updater.

The app is unpackaged and not code-signed, so Windows SmartScreen may warn on first launch.
