## Notka v0.2.0

### What's new

- **Self-update.** Notka checks GitHub Releases once a day (and from Settings) and offers new versions. Installing is one click: it downloads the package, verifies its SHA-256 checksum, replaces the files and restarts. If anything goes wrong during the copy, the previous version is restored. The daily check can be turned off in Settings.
- **One package.** The MCP server for AI agents (`Notka.Mcp.exe`) now ships inside the app folder. There is no separate MCP download anymore.
- **AI agent access switch.** A new setting (on by default) turns the bundled MCP server on or off. "Copy prompt" gives an agent the instructions to register the server itself, so Notka never edits other apps' configuration.
- **Taskbar strip.** Works on several monitors (primary, all, or a chosen one), can be shown as text only, and hides with an auto-hidden taskbar.
- **Settings.** The page scrolls, and the version and update status are shown in it.

### Upgrading from v0.1.0

v0.1.0 cannot update itself. Download `Notka-win-x64.zip` once, extract it over your Notka folder (or to a new one) and, if you use AI agents, point them at the new `Notka.Mcp.exe` from the app folder. From this version on, Notka updates itself.

### Downloads

- `Notka-win-x64.zip`: unzip and run `Notka.Desktop.exe`. No .NET installation needed.
- `Notka-win-x64.zip.sha256`: the checksum used by the updater.

The app is unpackaged and not code-signed, so Windows SmartScreen may warn on first launch.
