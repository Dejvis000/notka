## Notka v0.3.0

### What's new

- **Notes on the desktop.** Pull a note out of the list into its own small window, like Windows Sticky Notes. The window has the note's color, a delete button, a color picker and a "keep on top" switch. It saves as you type, remembers its position and size, and comes back after a restart.
- **One date and time picker.** The add-task row has a single "Termin" button that opens a calendar with clickable hour and minute lists and a box for typing a time such as `14:30`.
- **Start mode.** A new setting chooses what Notka does at start: the default (window by hand, tray only when started with Windows), the full window, the compact window, or tray only.
- **Settings in cards.** Settings are grouped into cards in two columns on a wide window and one column on a narrow one.
- **Cleaner install folder.** The package is now `Notka.exe` plus an `app` folder, instead of hundreds of files in one place. `Notka.exe` is a small launcher.
- **Faster start.** The app and the MCP server are precompiled (ReadyToRun): the window opens in about 1.3 s instead of 1.8 s (measured on one machine) and the API is ready in about 1.05 s instead of 1.6 s. The package is larger (about 131 MB zipped).
- **Calmer taskbar strip.** The strip no longer jumps around when the tray overflow is opened or tray icons are moved, and the taskbar scan pauses while the strip is switched off.
- **No lost text.** Text typed into a note while an earlier edit was still being saved is no longer overwritten.

### Updating from v0.2.2 or older

This version changes the folder layout, and the updater built into v0.2.2 cannot install it (it will report an incomplete package). Update once by hand:

1. Exit Notka from the tray menu.
2. Download `Notka-win-x64.zip` and extract it to a new, empty folder.
3. Run `Notka.exe`. Your tasks, notes and settings are kept in `%LOCALAPPDATA%\Notka`.
4. If "Start with Windows" was on, its switch will show as off in the new copy: turn it on again in Settings so it points to the new location. If an AI agent uses the MCP server, copy the agent prompt from Settings again, or edit the path in its configuration by hand: it is now `app\Notka.Mcp.exe`.
5. Delete the old folder.

From this version on, updates install from Settings as before.

### Downloads

- `Notka-win-x64.zip`: unzip and run `Notka.exe`. No .NET installation needed.
- `Notka-win-x64.zip.sha256`: the checksum used by the updater.

The app is unpackaged and not code-signed, so Windows SmartScreen may warn on first launch.
