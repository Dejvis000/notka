## Notka v0.2.2

### What's new

- **Task time.** The add-task row has a time picker next to the date, so tasks created in the app can be reminded 15 minutes before they are due. A time without a date means today.
- **Opening from the taskbar strip.** Clicking the strip next to the clock now brings the Notka window to the front instead of opening it behind other windows.
- **No more "Esc" tooltip** appearing when hovering over parts of the window.

### Updating

Notka offers this version from Settings (or within a day automatically) if you run v0.2.0 or v0.2.1. If you run v0.1.0, download `Notka-win-x64.zip` once and extract it over your Notka folder.

### Downloads

- `Notka-win-x64.zip`: unzip and run `Notka.Desktop.exe`. No .NET installation needed.
- `Notka-win-x64.zip.sha256`: the checksum used by the updater.

The app is unpackaged and not code-signed, so Windows SmartScreen may warn on first launch.
